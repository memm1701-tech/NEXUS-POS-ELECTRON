# NEXUS POS Global

Sistema de punto de venta, facturación fiscal, inventario, cuentas por cobrar/pagar, nómina y analítica BI desarrollado por **Nexus Company C.A.** (`Electron` + `Express` + `SQLite`).

## Scripts de Desarrollo y Validación

- `npm start`: Inicia la aplicación de escritorio Electron.
- `npm run validate`: Ejecuta la validación integral estática y de esquemas/queries SQLite en `:memory:`.
- `npm test`: Ejecuta la suite de pruebas automatizadas (`node --test`).
- `npm run dist`: Compila el instalador NSIS para Windows en `dist/`.
