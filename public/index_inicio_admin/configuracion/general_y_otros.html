Configuración de Sistema

calculate Modalidad de Cálculo de Precios y Margen de Ganancia

Seleccione cómo el inventario calcula automáticamente el precio de venta a partir del costo y el porcentaje de ganancia.

* Por defecto está activo el cálculo sobre costo tradicional (80 + 20% = 96). Si selecciona margen sobre venta, el porcentaje representará el margen comercial neto en inventario (80 + 20% = 100).

warning Desactivar Validación de Stock

Permite facturar productos aunque no haya existencia en el Servidor Main.

* Por defecto, Nexus POS siempre valida el stock. Marque esta casilla solo si desea vender en negativo.

terminal Mostrar Inicialización con Consola (DevTools)

Abre la ventana de consola técnica al iniciar la aplicación para ver todos los logs del sistema en tiempo real.

* Útil en proyectos compilados para diagnosticar errores de red, impresoras, base de datos e inicialización. Requiere reiniciar la app.
